Aim: This experiment is to understand the implementation of Object detection and tracking in computer vision applications.
Data Files: Basketball match (“match-a1.avi”) (Link: https://www.epfl.ch/labs/cvlab/data/data-pom-index-php/)

1. Read video file (.avi) in OpenCV. In each frame detect objects using a detection transformer. 
2. Use the bounding boxes obtained in step 1 to track objects (i.e give specific ids) across frames of the video. Mention the id for each detected object in the video.
