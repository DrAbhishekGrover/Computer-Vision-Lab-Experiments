Aim: This experiment is to understand the implementation of Scale Invariant Feature Transform (SIFT) and visualization of SIFT descriptors.

Data Files: data.coins() from skimage python package 

1. Find Blobs in given image using Laplacian of Gaussian (LoG) method and display the output.
2. Find Blobs in given image using Difference of Gaussian (DoG) method and display the output.
3. Find SIFT descriptors for the Blobs detected in step 2. Display descriptors for each of the 16 cells.
4. Display the 128 length descriptor vector obtained in step 3.
