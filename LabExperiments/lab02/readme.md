Aim: This experiment is to understand the effect and implementation of matrix transformations in computer vision applications.

Data Files: Images (grayscale_arrow.tiff)

(1) Read the grayscale image file “grayscale_arrow.tiff” using imageio library and generate an output image with following transformations: (a) Scaling, (b) Rotation, (c) Translation. The above transformation has to be implemented using Forward Mapping methodology.\ 
(2) Read the grayscale image file “grayscale_arrow.tiff” using imageio library and generate an output image with following transformations: (a) Scaling, (b) Rotation, (c) Translation. The above transformation has to be implemented using Inverse Mapping methodology.\ 
(3) (Exercise) The transformations in S.No. 2 were about the top left corner (origin). Implement all three transformations about the center of the image. Use Inverse Mapping methodology.
